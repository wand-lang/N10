# N10
System N &lt;-> System 1 &lt;-> System 0 - A Wand library for routing events to the cheapest level that can handle them, and turning repeated cases into code

Each event is acted on by the cheapest level of the system that can act on it with certainty.

- System 1 classifies events with a level of certainty.
- System 0 handles certain events.
- System N handles uncertain events.
- System 0 is expanded over time as events become certain.
